One original one-line joke about office life, under 200 characters. `main.py` (Python 3.13, standard library only, no network) writes exactly that line to `entry.txt` and prints it — nothing else. Deterministic: every run produces the same bytes.

## The joke

> My boss calls it synergy when he takes credit for my work, and initiative when I do his.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the 88-character line to `out/entry.txt` and prints it. Without `MAKEFUN_OUTPUT_DIR` it writes to `/output/entry.txt`, as the grader expects.
